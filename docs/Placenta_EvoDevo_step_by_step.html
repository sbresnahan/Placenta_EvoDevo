Placenta_EvoDevo walkthrough

Complete the shared setup, then follow the recipe for your cohort.

Part 1. Shared setup

1. Set the project paths

export PROJECT=/rsrch9/home/epi/bhattacharya_lab/data/Placenta_EvoDevo
export DATA_ROOT="$PROJECT/data"
export SCRIPTS_DIR="$PROJECT/scripts"
export POE_SITE_FILE="$SCRIPTS_DIR/config/seadragon.sh"
umask 077
cd "$SCRIPTS_DIR"

2. Prepare a cohort

Define this terminal helper to select a cohort and create its working copies:

use_cohort() {
  export COHORT="${1:?Cohort name required}"
  export CONFIG="$SCRIPTS_DIR/config/$COHORT.private.yaml"
  export COHORT_DIR="$DATA_ROOT/$COHORT"
  mkdir -p "$COHORT_DIR"/{manifests,raw,reference,private,work,scratch,logs,receipts}
  for SOURCE in "$SCRIPTS_DIR/manifests/${COHORT}_"*.tsv; do
    DEST="$COHORT_DIR/manifests/$(basename "$SOURCE")"
    [[ -e "$DEST" ]] || cp -- "$SOURCE" "$DEST"
  done
  [[ -e "$CONFIG" ]] || cp -- "$SCRIPTS_DIR/config/$COHORT.example.yaml" "$CONFIG"
}
use_cohort maize_B73_Ki11

Edit sample tables in $COHORT_DIR/manifests/ and settings in $CONFIG. The helper preserves existing working copies.

3. Check the tools

00_setup/preflight.sh "$CONFIG"

Expected output: Required tools and R packages are accessible.

Setup checks the native tools, scheduler command, R image, library, and packages. The existing --execute option performs the same check.

Native tools run on the host. bin/Rscript_sif runs R and initializes its library. Site settings are in config/seadragon.sh.

4. Job settings

The configuration stores queue, cores, memory, and wall time under lsf.stages. Memory values are numeric GB, with matching memory_value and reservation_value. [562] Public retrieval uses transfer. [561]

Work Queue Typical cores / GB Wall time
Retrieval transfer 1 / 4 02:00
Reference, pilot, models short 2 / 8 Set 02:59
Quantification, assignment medium 2 / 8 12:00

For existing private configurations, set reference, pilot, and model wall_time values to '02:59'.

Your site limits are: short under 3 hours, medium 4–24 hours, long 25–120 hours, 20 cores and 300 GB RAM per job. LSF enforces job limits. Pilot reports provide usage and runtime projections for choosing resources.

5. Follow submissions

Each recipe lists the submission and the outputs to inspect when its jobs finish.

bjobs -a
ls -lt "$COHORT_DIR/logs/lsf/"
ls -lt "$COHORT_DIR/private/"jobs_*.submitted.tsv
bin/Rscript_sif poe.R "$CONFIG" status

The terminal prints each submitted job ID and the job-record filename. View an individual job or log with:

read -r -p "Job ID: " JOB_ID
bjobs -l "$JOB_ID"
read -r -p "Log filename: " JOB_LOG
less -S "$JOB_LOG"

status reports completed stages and their required outputs. After an input or setting changes, rerun the affected stages and their dependents. A command without --submit prints a plan.

B73 Sample_16 ERR2889297, ERR2889298

The supplied strand is fr, dosage is maternal:paternal 2:1, and compressed RNA totals 52,116,556,804 bytes. The tables already group runs into the four pools.

K2. Retrieve the inputs

bin/submit_pipeline.sh "$CONFIG" retrieve --submit

One job downloads RNA, the B73 RefGen_v4/AGPv4 genome, F1maize.FINAL.gff from Zenodo record 2611319, and ten raw AGPv4 chromosome VCFs. When it finishes:

less -S "$COHORT_DIR/resource_receipt.tsv"
ls -lh "$COHORT_DIR/raw/"
ls -lh "$COHORT_DIR/reference/"

Retrieval checks source MD5/bytes, gzip integrity, and FASTQ structure/mates.

K3. Build the reference

bin/submit_pipeline.sh "$CONFIG" reference --submit

Three jobs build the transcript/promoter catalog, B73/Ki11 markers, and index. Marker preparation uses depth ≥5, allele fraction ≥0.9, and REF agreement ≥99%. When the jobs finish:

bin/Rscript_sif poe.R "$CONFIG" status
less -S "$COHORT_DIR/annotation_audit.tsv"
less -S "$COHORT_DIR/markers.tsv"
ls -lh "$COHORT_DIR/reference/personal.index"

Expected status: reference complete.

K4. Run the pilot

bin/submit_pipeline.sh "$CONFIG" pilot --submit

Five jobs run four library pilots and collect their metrics. When they finish:

bin/Rscript_sif poe.R "$CONFIG" status
less -S "$COHORT_DIR/pilot_report.tsv"

Expected status: pilot complete. Diagnostics use 100,000 fragments per strand and a one-million-fragment throughput prefix per library. The report includes pseudoalignment, time, RSS, index size, endpoint work bytes, and projected quantification time. Projections are informative.

K5. Quantify all four libraries

bin/submit_pipeline.sh "$CONFIG" scale --submit

Nine jobs perform quantification, parental assignment, and collection. When they finish:

bin/Rscript_sif poe.R "$CONFIG" status
less -S "$COHORT_DIR/work/Sample_15/complete/fr/assignment_qc.tsv"

Expected status: quantification complete. Each library has an assignment_qc.tsv under its configured strand directory.

K6. Fit the models

bin/submit_pipeline.sh "$CONFIG" models --submit

When the model job finishes:

less -S "$COHORT_DIR/model_gene.tsv"
less -S "$COHORT_DIR/model_promoter.tsv"
less -S "$COHORT_DIR/model_pairs.tsv"

Expected status: models complete. Public effects use the 2:1 dosage offset.

data/GUSTO/private/typed.vcf.gz
data/GUSTO/private/personalization.vcf.gz

Typed mother/father/child genotypes supply parental anchors. Center numeric covariates for the configured model.

Part 7. Results

File Contents
annotation_audit.tsv Reference and transcript checks
events.tsv, pairs.tsv Promoter groups and comparisons
pilot_report.tsv Per-library diagnostics, measured usage, runtime projection
assignment_qc.tsv Coordinate and parental-assignment status by library
model_gene.tsv, model_promoter.tsv Effect estimates, uncertainty, q-values, eligibility status
model_pairs.tsv Paired observations used by the model

Primary promoter groups use fixed-anchor 50-bp windows; 25/100-bp catalogs are also written. Public models use coverage-selected sentinels, dosage-adjusted log2 ratios, and reciprocal-cross orientation. Missing parental evidence is NA.

Human promoter models use natural-log contrasts, cis orientation, and configured covariates. Eligibility requires depth ≥20, ≥10 families, ≥3 maternal-REF and maternal-ALT orientations at both sentinels, and ≥5 residual degrees of freedom. Inference uses HC3 t statistics and 2,000 family bootstraps, seed 1147, with ≥90% valid fits. The q≤0.05 and absolute contrast≥log(2) flag denotes conditional discordance.
