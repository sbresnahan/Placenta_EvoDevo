Approval fields are attestations, not instructions to fabricate evidence. Empty/unresolved input contracts must be completed; setting a flag does not create a reference, genotype table, independent replicate or identity link.

Installed-tool identity

With SCRIPTS_DIR, POE_SITE_FILE and absolute CONFIG set:

00_setup/preflight.sh "$CONFIG"
00_setup/preflight.sh "$CONFIG" --execute

The first command checks metadata. The second inventories actual host binaries and checks R dependencies separately. It does not install tools, download data or submit jobs. The pending inventory path is printed before acceptance. Review that file privately if a gate fails.

The inventory lists executable paths and available versions, configured site/image paths, and Python package information. Ornaments is already installed in the Conda environment /rsrch5/home/epi/bhattacharya_lab/software/ornaments. No source-build evidence or software checksum entry is required.

Success: required commands/environments and R packages are available, and the selected metadata pass validation. Failure: resolve missing commands, library/image/package problems, or bad manifests locally; do not reinstall software merely to bypass a check.

Metadata preflight does not certify that all reference/read inputs exist, that LSF policy is correct or that models will be eligible. GUSTO's empty schemas cannot pass until real private linkage/QC is supplied.

Resource review

The YAML's queue/CPU/RAM/time values are initial templates, not measurements. Confirm the site's memory limit and reservation units; do not translate values from another cluster by guesswork. Native thread count cannot exceed allocated CPUs. Review public input totals from manifests and actual local GUSTO inventory.

Use the bounded pilot's measured RSS/time and actual index sizes to choose allocations and review total runtime/storage. Projection covers quantification, not all downloading, indexing, startup or queue delays. Endpoint work size is not a disk high-water mark. Container startup/I/O overhead also needs site observation.

Analysis rules

These are interpretation/eligibility contracts, not optional setup shortcuts:

  • Promoter groups use a fixed TSS anchor, a primary 50-bp window and compatible first donor; no transitive chaining. The 25/100-bp catalogs are structural sensitivity views, not evidence of tested expression-model robustness.
  • Expected allocations are combined at the same event/genomic locus, not summed across SNPs as independent molecules. Missing parental evidence remains NA.
  • One sentinel per entity is selected by coverage across every configured primary unit with depth at least 20, not by imbalance. Promoter-pair selection is likewise coverage-based.
  • Public gene outcomes are log2((M + 0.5)/(P + 0.5)) minus log2(maternal_dose/paternal_dose). Promoter contrasts are within-unit differences, so this dosage offset cancels.
  • Public inference uses an unweighted intercept plus reciprocal-cross orientation. Residual degrees of freedom are independent-unit n minus model rank. One direction, repeated/unresolved clusters, missing units, insufficient coverage or nonpositive residual df blocks POE inference.
  • BH adjustment is separate by cohort, stage, species and endpoint. Do not combine results as extra replicates or silently change the testing family.
  • Human inference uses the paired natural-log promoter contrast, cis-orientation terms and approved centered covariates. Only exact equal/opposite cis redundancy is removed; otherwise full rank is required.
  • Human eligibility requires depth at least 20/event, ten paired families, three maternal-REF and three maternal-ALT orientations at both sentinels and at least five residual df. HC3 t inference and 2,000 family bootstraps use seed 1147 and require at least 90% valid bootstrap fits.
  • Human q <= 0.05 and absolute contrast at least log(2) flag conditional discordance, not definitive imprinting. Uncertainty is conditional on quantification and marker assumptions.

Maternal seed-coat/decidua/blood admixture, cis effects, genotype proxies and developmental composition remain alternative explanations. Human whole-gene analysis/masking and TE comparisons are outside the implemented workflow.
