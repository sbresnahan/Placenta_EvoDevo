# Fish P. prolifica: assembly-contig and GEO crosswalk

Inputs: Zhang et al. *Science Advances* (2026), DOI `10.1126/sciadv.aeh5487`, Dryad `10.5061/dryad.ns1rn8q8r`, RNA-seq GEO `GSE318355`, SRA `SRP674561`.

These steps are **read-only relative to active cohort manifests and markers**. The inputs for the SNP panel are the 53,734 RNA-supported candidate TSV generated by `prepare_fish_published_like_markers.py` (from DataS1/2/3), **not** any clinical or human data. The scripts never fabricate haplotype or run-to-sample assignments.

## 1. Stage and cross-design audit

The 11 Dryad placenta aliases comprise 3 A6×A6 controls (stages 35,45,40), 2 B3×B3 controls (stage 40), 3 A6×B3 F1 (stages 40,45,45), and 3 B3×A6 F1r (all stage 40). Thus the six biological F1 placentas span stages 40 and 45, and all stage-45 F1 placentas are A6×B3. Cross and stage are **imbalanced**. An unadjusted reciprocal-intercept test may be stage-confounded. Current `load_manifests()` in `R/config.R` rejects multiple stage values in one `public_cross` configuration; do not relabel samples to conceal stage heterogeneity. Consider an explicit stage-aware model and stage-40 sensitivity analysis after identities are verified, with low N acknowledged.

## 2. Check genomic contig naming and alias provenance

The paper's Dryad SNP-calling script cites `poePro_genome_v2.fa`. The cohort config cites `GCF_027474105.1` (Auburn_PproV2). Even if these are representations of the same assembly, exact coordinate compatibility must be demonstrated.

```bash
cd "$SCRIPTS_DIR"
export COHORT_DIR=/rsrch9/home/epi/bhattacharya_lab/data/Placenta_EvoDevo/data/fish_Pprolifica_AB
export DRYAD="$COHORT_DIR/reference/doi_10_5061_dryad_ns1rn8q8r__v20260930"
export GENOME="$COHORT_DIR/reference/genome.fa"
export CAND="$COHORT_DIR/reference/dryad_lineAB_published_like_v1/lineA_lineB.published_like_candidates.tsv"

bin/native/samtools faidx "$GENOME"  # if an index has not already been made
head -4 "$GENOME.fai"

# Optional, on a transfer node or a host permitted to access NCBI:
REPORT="$COHORT_DIR/reference/GCF_027474105.1_Auburn_PproV2_assembly_report.txt"
curl -fL --retry 3 \
  'https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/027/474/105/GCF_027474105.1_Auburn_PproV2/GCF_027474105.1_Auburn_PproV2_assembly_report.txt' \
  -o "$REPORT"

python3 bin/audit_fish_contig_aliases.py \
  --candidates "$CAND" --genome-fai "$GENOME.fai" \
  --assembly-report "$REPORT" \
  --out-dir "$COHORT_DIR/reference/fish_alias_audit_v1"
```

The report is optional if all SCAFFOLD names appear directly in the FASTA `.fai`; omit `--assembly-report` in that case. The audit only matches **literal names or aliases in the NCBI assembly report, with length concordance**; it does not assume SCAFFOLD numbers match NCBI accessions by rank. Inspect `fish_contig_alias_report.json` and `fish_contig_alias_audit.tsv`. It emits `verified_contig_aliases.tsv` but not active markers.

### REF-base validation and candidate promotion (only if contig audit supports it)

Generate a **new, versioned output directory**; the candidate-builder refuses overwrite. It will independently verify all REF bases via FASTA + `.fai`, require ≥99% matches by default, and write a six-column production-format file only if the threshold passes.

```bash
python3 bin/prepare_fish_published_like_markers.py \
  --datas1 "$DRYAD/DataS1.csv" --datas2 "$DRYAD/DataS2.csv" \
  --datas3 "$DRYAD/DataS3.csv" \
  --genome "$GENOME" \
  --contig-map "$COHORT_DIR/reference/fish_alias_audit_v1/verified_contig_aliases.tsv" \
  --out-dir "$COHORT_DIR/reference/dryad_lineAB_published_like_genome_v1"
cat "$COHORT_DIR/reference/dryad_lineAB_published_like_genome_v1/lineA_lineB.published_like_report.json"
```

**Do not edit `manifests/fish_Pprolifica_AB_marker_sources.tsv` until the genome audit passes, and the RNA-derived origin proxy and limitations have been reviewed.** A base match confirms the reference nucleotide, not parental-line homozygosity independently of RNA expression.

## 3. Crosswalk GEO samples to Dryad aliases

RunInfo's `Sample Name` column contains GSM identifiers, not experimental aliases. Obtain the official `GSE318355_family.soft.gz` and feed it to the converter. If GEO is unreachable, run without `--geo-soft` to produce an explicit 11-run unresolved draft; never infer assignments from SRA order.

```bash
GEO="$COHORT_DIR/reference/GSE318355_family.soft.gz"
curl -fL --retry 3 \
  'https://ftp.ncbi.nlm.nih.gov/geo/series/GSE318nnn/GSE318355/soft/GSE318355_family.soft.gz' \
  -o "$GEO"
python3 bin/build_fish_geo_crosswalk.py \
  --runinfo manifests/fish_Pprolifica_AB_SraRunTable.csv \
  --datas1 "$DRYAD/DataS1.csv" \
  --geo-soft "$GEO" \
  --out-dir "$COHORT_DIR/manifests/fish_geo_crosswalk_v1"
```

Outputs: `fish_placenta_geo_dryad_crosswalk.tsv`, `fish_placenta_geo_dryad_crosswalk_report.json`, `fish_placenta_dryad_design.tsv`. Exact alias matches can populate stage and parental labels; `include` remains `NO` until verified and reviewed. If GEO titles use nonliteral aliases, a separate independent metadata confirmation is required.
