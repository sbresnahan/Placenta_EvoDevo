# 05 — Parental assignment

Included after each library's quantification in the `scale` graph.

Inputs: Ornaments expected allelic allocations, transcript/exon/event maps,
and public markers or typed trio anchors.

Outputs: `gene_counts.tsv`, `event_counts.tsv`, `assignment_qc.tsv`, and
assignment completion records. Assignment combines expected allocations at
the same genomic locus. Missing parental evidence is NA.
